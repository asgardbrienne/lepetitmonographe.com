# Le Petit Monographe

Site statique (HTML/CSS, sans dépendance) de lepetitmonographe.com.

Les pages sont produites par `outils/generer.py` : modifier ce script puis lancer

    python3 outils/generer.py .

Les éléments surlignés en jaune hachuré (classe `a-completer`) sont à remplir avant la mise en ligne.
